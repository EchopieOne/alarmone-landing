Choose your own alarm sound

To set a custom alarm sound on iPhone without GarageBand, choose a song in Clock’s Sound settings, or import an audio file into Alarm One. Alarm One’s direct import supports MP3, WAV, AIFF, CAF, and M4A on iOS 26.1 or later with Pro.

Quick choice

For a song available in your Music library, use the regular Clock alarm’s song picker. For a playable audio file in Files, use Alarm One’s Custom Ringtone → Upload Ringtone.

What to check: Alarm One audio import requires Pro and iOS 26.1 or later. A streaming link or an app’s protected offline download is not a supported audio file.

Use a song in iPhone Clock

  1. Open a regular Clock alarm

    Go to Clock → Alarms, then add an alarm or open an existing one.

  2. Open Sound and choose a song

    Use the song picker to select a track available in your Music library. This does not import an MP3 from Files.

  3. Save and test the alarm

    Check that the selected track is available on the device, then create a short test alarm before relying on it.

Use the regular alarm editor for this method. The Sleep/Wake Up alarm has its own Sounds & Haptics options and does not share every setting with a regular alarm.

Source: Apple: choose a song or ringtone for a Clock alarm.

Import a sound from Files

If you already have a usable audio file, Alarm One can select it directly from Files. The import control requires iOS 26.1 or later and Alarm One Pro. Supported formats are MP3, WAV, AIFF, CAF, and M4A; the file must contain playable audio.

  1. Save your sound in Files

    Use your own recording or an audio file you have permission to use. Download an iCloud file locally if it is not yet available.

  2. Open the alarm’s sound selector

    Create or edit an Alarm One alarm and open its sound options.

  3. Choose Custom Ringtone → Upload Ringtone

    Select the file from Files. If prompted, unlock Pro to access custom import.

  4. Select the imported sound and save

    Preview the sound, select it for the alarm, and save the alarm. Use a test alarm to check playback.

For a nap or temporary alert, pair the sound with a self-deleting alarm. For an exam-day wake-up, add a specified date.

Use a Voice Memo as your sound

Record the cue in Voice Memos, use its sharing options to save the recording to Files, then choose that file in Alarm One’s ringtone importer. A playable M4A recording is a supported format. Speak clearly and leave little silence at the beginning so the alert starts promptly.

If you want that recording in Apple’s system ringtone collection instead, Apple documents a GarageBand export workflow. That workflow creates a ringtone of up to 30 seconds and then lets you assign the exported tone. Direct Alarm One import uses the app’s own sound selection.

Source: Apple: create a custom ringtone.

Music services and alarm sounds

  • Apple Music: Clock can select library songs. A song that works in Clock is not necessarily an unprotected file that a third-party importer can open.
  • Spotify: a Spotify link or in-app offline download is not an MP3 in Files. Alarm One’s importer takes audio files; it does not play Spotify streams.
  • TikTok: a video or share link is not a supported audio file. If you own a recording or have permission to use it, prepare a playable file before importing.

An importer cannot remove DRM from a protected track. Apple’s GarageBand documentation also distinguishes protected songs from usable audio files. Use a compatible recording or a built-in tone when a file cannot be opened.

When your sound will not play

  • Wrong alarm type: edit the regular alarm you actually enabled, especially if you also use a Sleep/Wake Up schedule.
  • Unavailable or unplayable file: open the file on the device and verify that it contains audio; a renamed extension does not convert it.
  • Wrong sound selection: return to the alarm and confirm the imported tone is selected.
  • Volume or None: check the alarm sound and the relevant volume controls in Settings → Sounds & Haptics. On versions with Alarms and Timers controls, review that section; older versions use Ringtone and Alerts.
  • App access: check Alarm One’s alarm authorization and its iOS version and Pro requirements for import.

For Clock specifically, Apple states that Silent mode and Focus do not silence alarms, and connected headphones do not suppress the built-in speaker. Avoid treating either as the automatic explanation for a silent alarm.

Source: Apple: troubleshoot alarm sound and volume.

Common questions

Can I set a custom alarm sound on iPhone without GarageBand?

Yes. Select a library song in a regular Clock alarm, or use Alarm One to import a playable MP3, WAV, AIFF, CAF, or M4A. Alarm One import requires iOS 26.1 or later and Pro.

Can I use a Spotify song directly in Alarm One?

Alarm One imports playable audio files from Files. A Spotify link or Spotify offline download is not a supported audio-file import.

Is custom ringtone import free in Alarm One?

Custom ringtone import requires Alarm One Pro and iOS 26.1 or later. You can use the available built-in sounds without importing a file.

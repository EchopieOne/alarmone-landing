An alarm every other day

To set an alarm every other day on iPhone, use a two-day rotation: one day with an alarm, followed by one day without one. In Alarm One, choose Workday → Rotation, set the first alarm date, and enter 1 work day and 1 rest day.

Quick setup

Choose Rotation, set the first date that should ring, and enter 1 work day plus 1 rest day. Check that the next alarm dates remain two calendar days apart.

What to check: A Monday/Wednesday/Friday repeat does not mean every other day. A calendar-day cycle is also different from exactly 48 elapsed hours around daylight saving changes.

Why weekday repeats differ

Three weekday checkboxes leave a three-day gap from Friday to Monday. Adding Sunday fixes that gap but creates back-to-back alarms on Sunday and Monday. A true alternate-day pattern moves through the week instead of repeating the same weekdays.

For example, a cycle starting October 1, 2026 rings on October 1, 3, 5, 7, and 9. The weekdays change, but the spacing stays at two calendar days.

Set a two-day alarm cycle

  1. Choose the alarm time

    Create an alarm at the wake-up or task time you want.

  2. Select Workday → Rotation

    Enter the first day you want the alarm to ring as the start date.

  3. Set 1 work day and 1 rest day

    The alarm rings on the work day, stays silent on the rest day, and repeats.

  4. Review the upcoming dates

    Check several occurrences, including the start of the following week.

The work/rest labels describe which days ring. You can use this pattern for alternating work days, study sessions, or household tasks. For longer cycles, see the rotating shift alarm guide.

Use the built-in iPhone apps

Clock is useful when the same weekdays repeat every week. For alternating dates, Calendar can track a recurring event with a custom interval where available; check its occurrence dates and add an alert. Those are event notifications, so confirm their delivery settings.

For a few isolated dates, enter separate future-date alarms instead of building a cycle. When the pattern continues for months, a repeating rotation makes the next dates easier to review.

Skip a day or change the start

If you skip a single occurrence, keep the original cycle anchor. Moving the start date shifts all subsequent alarm days. Use the skip control for a temporary exception, and edit the start date only when the intended pattern itself changes.

“Every other day” generally means every second calendar day at a chosen local time. That differs from exactly 48 elapsed hours when daylight saving time changes. Decide which behavior your schedule calls for.

Common questions

Can Clock repeat an alarm every two days?

The regular Clock editor repeats selected weekdays. An alternate-day cycle crosses weekdays, so use a rotation or schedule individual future dates.

What values should I enter in Alarm One?

Choose Rotation, set the first alarm date, and use 1 work day plus 1 rest day. Review the upcoming dates to confirm the pattern.

Does skipping an occurrence restart the cycle?

A temporary skip should keep the cycle anchor. Change the start date only when you want to change which dates belong to the pattern.

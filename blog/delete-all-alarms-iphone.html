How to delete all alarms on iPhone with Siri or Shortcuts

To delete all alarms on iPhone, try asking Siri to “Delete all my alarms,” then review the confirmation and check Clock. To keep some alarms, delete entries individually or use Shortcuts to select a batch. Clear only the alarms you no longer need.

What should you keep before clearing the alarm list?

Write down the times, weekdays, labels, and sounds of recurring alarms you still use. Deleting an entry removes its saved settings, while switching it off keeps it available. If only a few old alerts are cluttering the list, selective cleanup is quicker than rebuilding your daily wake-ups.

Clock alarms, Sleep/Wake Up schedules, and Alarm One alarms have separate controls. Check each place where you created an alert. A clean Clock list does not tell you whether a Health sleep schedule or a third-party alarm remains active.

How do you ask Siri to delete all iPhone alarms?

  1. Open Siri

    Activate Siri using your usual button or voice method.

  2. Request the alarm cleanup

    Say “Delete all my alarms.” Read or listen to Siri’s response and confirm only if the intended alarms are selected.

  3. Check Clock → Alarms

    Verify that the entries you intended to remove are gone. If Siri does not support the request in your current setup, use Clock or Shortcuts below.

Siri’s response can vary by iOS version, language, and device setup. A request to turn alarms off leaves the saved entries in place; check that the result is deletion.

How do you remove selected alarms directly in Clock?

Open Clock → Alarms, swipe left on an obsolete entry, and tap its delete or trash control. Repeat for the entries you no longer use. This preserves the other alarms and makes it easy to check labels as you clean up.

How do you build a batch-delete shortcut?

Use this workflow if your iOS version exposes the Clock actions for retrieving and deleting alarms. Action names and prompts can differ by version and language; search the Clock action list for “alarm.”

  1. Get the alarm list

    In a new shortcut, add Clock’s Get All Alarms action, or the equivalent action that returns the alarm list.

  2. Choose which alarms to delete

    Add Choose from List using that result and enable Select Multiple. Select only obsolete entries when running it.

  3. Delete each selected entry

    Add Repeat with Each for the chosen items. Inside the loop, use Clock’s Delete Alarms action, or the equivalent deletion action, with Repeat Item as its input.

  4. Keep the first run small

    Run it against an expendable test entry, review deletion prompts, and verify the result in Clock before selecting a larger batch.

For a complete reset, feed the whole retrieved list into the repeat loop only when you intend to remove every returned alarm. If your version does not offer a deletion action, use Clock’s individual delete control. Turning a switch off is a different operation.

Batch cleanup removes old entries when you run it. It does not automatically remove tomorrow’s temporary alarm. For that behavior, see how to automatically delete alarms after they ring.

Why is the Sleep/Wake Up alarm still there?

The wake-up alarm tied to a Health sleep schedule uses separate controls. In Clock, open the wake-up alarm’s Change controls to edit the next occurrence, or open the sleep schedule in Health to edit its recurring pattern.

Review whether you want to skip one wake-up or change the schedule itself. Those changes serve different purposes.

How do you keep temporary alarms from building up again?

Reuse a daily wake-up when the schedule stays the same. For a nap, flight, or single appointment, create a temporary Alarm One alarm and enable “Delete this alarm after it rings.” This applies to alarms created in Alarm One; existing Clock entries still need separate cleanup.

You can also give temporary alerts recognizable custom alarm sounds and assign the exact future date when needed. A clear label and next occurrence make the list easier to review.

What else should you know?

Can I clear every alarm with Siri?

Try “Delete all my alarms,” review Siri’s response, and check the result in Clock. Availability and confirmation can vary by iOS version, language, and device setup.

Does deleting Clock alarms remove my sleep schedule?

Sleep/Wake Up alarms have separate schedule controls in Clock and Health. Review the sleep schedule separately.

Can Alarm One clean up existing Clock alarms?

Alarm One’s auto-delete option applies to its own alarms. Use Clock, Siri, or available Shortcuts actions to clear Clock entries.
